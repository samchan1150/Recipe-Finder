# Recipe Finder

## Overview

The Recipe Finder is a web application that allows users to search for recipes based on meal names, categories, areas, or ingredients. Users can also explore random recipes using the "I'm Feeling Lucky" feature. The application fetches data from TheMealDB API, providing detailed information about various meals, including ingredients, preparation steps, and YouTube links for video instructions.

## Features

- Search for recipes by meal name, category, area, or ingredient.
- Filter results based on selected categories, areas, and ingredients.
- View detailed information about each recipe, including ingredients and preparation steps.
- "I'm Feeling Lucky" button to fetch and display a random meal.
- Responsive design for a better user experience on different devices.

## Technologies Used

- HTML
- CSS
- JavaScript
- TheMealDB API

## Getting Started

### Prerequisites

To run this application, you need a modern web browser (Chrome, Firefox, Safari, etc.) that supports JavaScript.

### Installation

1. Clone the repository or download the source code.

   ```bash
   git clone https://github.com/yourusername/recipe-finder.git
   ```

2. Navigate to the project directory.

   ```bash
   cd recipe-finder
   ```

3. Open the `index.html` file in your preferred web browser.

### Usage

1. Enter a meal name in the search box and click "Search" to find recipes.
2. Use the dropdown menus to filter by category, area, or ingredient.
3. Click the "I'm Feeling Lucky" button to see a random meal.
4. Click on a recipe to view detailed information, including ingredients and preparation steps.
